➕ Criar Novo Sub-projeto

Cria automaticamente toda a estrutura padrão de um sub-projeto novo:
pasta + README + ctx_*.md + TAREFAS_*.md + registra keyword

python criar_projeto.py
  1. Abre terminal na pasta Documentos/PAINEL_MESTRE/
  2. Roda python criar_projeto.py
  3. Responde: nome do projeto, ramo (FR/LU/Outro), keyword
  4. Script cria pasta + 3 arquivos padrão + atualiza PALAVRAS_CHAVE.md
  5. Roda python gerar_dashboard.py pra ver aparecer aqui

🎯 Auto-descoberta: qualquer pasta com ctx_*.md no padrão é detectada automaticamente. Não precisa editar listas em lugar nenhum.
